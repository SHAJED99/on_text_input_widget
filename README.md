# Flutter Text Input Widget with Search

Feature-rich text input with built-in search functionality.

## Features
- Text input with search
- Input validation
- Clear button
- Search suggestions
- Custom styling

## Usage
```dart
OnTextInput(
  onSearch: (q) {
    print("Searching: $q");
  },
  hintText: "Search...",
)
```

## Installation
```yaml
dependencies:
  on_text_input_widget: ^1.0.0
```
